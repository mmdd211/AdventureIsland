# 冒险岛物语（AdventureIsland）

一款使用 Godot 4.7 制作的横版像素冒险平台跳跃游戏。玩家从初始草原出发，穿越六大主题区域，击败沿途怪物，最终抵达天穹之门完成通关。

## 游戏特色

- **六大主题区域**：初始草原、蘑菇森林、低语树洞、风哨峡谷、苔石遗迹、天穹之门，每个区域拥有独立配色、地形与敌人布置，通过传送门依次连通。
- **三种基础敌人**：蘑菇正面推进，蜗牛具备正面格挡与背击弱点，史莱姆被击败后会分裂成两只更具攻击性的小史莱姆。
- **像素美术运行时生成**：地形、传送门、金币与角色均由 `PixelStyleManager` 在加载阶段逐帧生成像素位图，无需外部美术资源即可呈现统一像素主题。
- **程序化芯片音乐**：背景音乐与音效全部由 `AudioManager` 实时合成波形，标题曲与关卡曲风格独立。
- **沉浸式开始与加载流程**：动态标题屏包含飘动云层、像素雪山与弹跳史莱姆装饰；点击开始后进入分阶段加载界面，音乐合成与区域搭建实时汇报进度。
- **完整局内体验**：暂停菜单、死亡与复活、检查点存档、金币收集、经验奖励、通关评价，以及 Tab 键呼出的世界地图。
- **敌人传送门边界**：传送门两侧生成仅对敌人生效的隐形边界，怪物巡逻、冲锋或跳跃都不会越过传送门。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| A / D | 左右移动 |
| W / 空格 | 跳跃 |
| J | 攻击 |
| K / Shift | 冲刺 |
| Tab | 世界地图 |

## 运行方式

1. 安装 [Godot 4.7](https://godotengine.org/download) 或更高版本。
2. 使用 Godot 打开本项目根目录的 `project.godot`。
3. 点击运行（F5）即可从标题屏开始游戏。
